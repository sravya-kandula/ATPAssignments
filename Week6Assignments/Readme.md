### JavaScript `map()` Function

The `map()` function was used to work with arrays and dynamically transform data.

#### Features of `map()`

* Iterates through array elements
* Creates a new transformed array
* Reduces repetitive code
* Helps in dynamic rendering of content

#### Example

```javascript
const products = ["Laptop", "Phone", "Watch"];

const updatedProducts = products.map(product => product.toUpperCase());

console.log(updatedProducts);
```
