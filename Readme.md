# User Management App

## Project Overview
The User Management App is a web-based application developed using **Vite + React** for managing user information efficiently.

The application is designed to demonstrate concepts such as:
- Component-based architecture in React
- Routing and page navigation
- State management using React Hooks
- Form handling
- Dynamic rendering of user data
- Modern frontend development using Vite

---

## Technologies Used
- **React.js** – For building the user interface
- **Vite** – Fast frontend build tool and development server
- **JavaScript (ES6)** – Application logic
- **HTML5 & CSS3** – Structure and styling
- **React Hooks** – State and lifecycle management

---

## About Vite + React
The project is built using **Vite with React**. Vite is a modern frontend development tool that provides:
- Faster development server startup
- Instant hot module replacement (HMR)
- Optimized production build
- Better performance compared to traditional bundlers

# Application Pages

## Home Page
The Home Page acts as the main landing page of the application.

### Features:
- Welcome message for users
- Simple and clean UI
- Navigation links/buttons
- Responsive design

---

## Add User Page
The Add User Page is used to insert new user details into the application.

### Features:
- User input form
- Form validation
- Add new user functionality
- Dynamic state handling using React Hooks

---

## Users List Page
The Users List Page displays all the added users in a structured format.

### Features:
- Display list of users
- Dynamic rendering using React
- Organized user information
- Easy readability and management

## Conclusion
The User Management App is a beginner-friendly React project that demonstrates modern frontend development concepts using Vite and React.
